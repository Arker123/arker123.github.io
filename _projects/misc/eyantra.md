We participated in **eYRC 2023-24**, tackling the theme **“GeoGuide”**, which centered around developing an advanced robotic vehicle named **Vanguard**. The project involved:  

- **Task**: Building an autonomous robot guided by an overhead static drone, "Watchtower," to navigate a war-torn arena, avoid danger zones, and adapt to simulated events like alien attacks.  
- **Core Technologies**:  
  - **Image Processing**: Using an overhead camera for navigation and real-time event detection.  
  - **Machine Learning**: Implementing algorithms to process data and respond to dynamic situations.  
  - **Georeferencing**: Determining Vanguard's position in the arena for precise navigation.  
  - **Shortest Path Algorithms**: Ensuring efficient route planning.  
  - **Wireless Communication**: Facilitating coordination with the command center.  

I reached the penultimate round of the competition, gaining hands-on experience with cutting-edge technologies like the ESP32 microcontroller, GIS, and robotics system design. This journey honed my skills in automation, problem-solving, and collaborative teamwork, providing a deeper understanding of real-world robotics challenges.
