### Unleashing the Power of FLOSS: Enhancing String Extraction for Go and Rust  
**Google Summer of Code 2023**  

During GSoC 2023, I worked with the Mandiant FLARE team to enhance FLOSS, enabling language-specific string extraction for Go and Rust executables. Key achievements include:  

- **Go**:  
  - Developed Go language identification and string extraction modules.  
  - Achieved 98% accuracy in string extraction for unknown Go binaries.  

- **Rust**:  
  - Built modules for Rust language identification and string extraction.  
  - Ensured over 90% extraction success for unidentified Rust binaries.  

- **General**:  
  - Automated binary generation with Docker.  
  - Improved CI pipelines for robust version coverage.  

#### Future Work  
Expand support to other languages (e.g., .NET), optimize performance, and build a user-friendly interface.
