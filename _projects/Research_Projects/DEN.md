## Abstract

This work introduces a novel architecture called the Divergent Ensemble Network (DEN), which is designed to improve uncertainty estimation in neural networks. Traditional ensemble methods often face challenges like computational inefficiency and parameter redundancy. DEN addresses these by combining shared representation learning with independent branching, offering both computational efficiency and robust predictions.
Key Features

- Shared Input Layer: Captures common features across ensemble members, reducing computational redundancy.
- Independent Branching Layers: Maintains diversity in predictions while improving variance.
- Performance Improvements: Enhanced computational efficiency and uncertainty estimation, suitable for real-time and critical applications.

DEN outperforms conventional methods in scenarios requiring high accuracy and reliable uncertainty predictions. The research demonstrates its potential in areas like real-time analytics and medical image analysis.
